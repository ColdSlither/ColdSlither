## What this is

One house, four divisions, one rule: **the work ships open, and nobody gets
credit stolen.**

| Division | Signal | What it does |
|----------|--------|--------------|
| **ATLAS** | Radar | A minimal, token-efficient coding-agent harness. Built for air-gapped and regulated environments (ITAR, CMMC, DFARS) where every line is auditable. Thesis: *the model is not the agent.* |
| **INTRONTERMINAL** | Cursor | A local LLM pipeline: SFT, alignment work, eval, serving. Own your model end to end. |
| **INTROSTUDIO** | Node | The creative side: local image and model workflows, no cloud leash. |
| **ARMOR** | Shield | The interface layer: dashboards and GUIs that surface what the agents are doing. |

The full INTRON brand system — logo marks, design tokens, booklets — lives in
the `/svg` and `booklets` artifacts of this and the division repos.

## The actual work

Most of what's under this account is a laboratory and a set of curated forks
(which point to their true upstreams). The genuinely owned projects are the
ones I built:

- **Atlas** — the agent harness. Token efficiency as a design principle, not a
  bolt-on. Provider-agnostic, no telemetry, bounded orchestrator loop. Built
  for environments where every line must be auditable.
- **IntronTerminal** — a local LLM pipeline: SFT, alignment work, eval,
  serving. The model on your disk answers to you.
- **IntronStudio** — the creative side: local image and model workflows.
- **Armor** — the Atlas interface layer (itself inspired by
  `pewdiepie-archdaemon/odysseus`, credited in that repo).
- **Codex-Intel-Builder** — tooling that re-architects an ARM Codex macOS DMG
  to run on Intel Macs.

The rest of the profile — OBLITERATUS, llama.cpp, T3MP3ST, heretic,
jailbreak-autoresearch, and the long tail of forks — is **work I study, fork,
and build on, not work I claim.** Each links to its real author. The fork
relationship is the credit; I don't relabel it as mine.

## Principles

- **Self-hosted by default.** Your data, your hardware, your inference. Cloud
  is a choice, never a requirement.
- **Auditable over magical.** If a system can't be inspected, it can't be
  trusted. Regulated environments don't accept black boxes, and neither do I.
- **Local models are a right.** Uncensored, honest, controllable — the weight
  on your disk answers to you.
- **Credit is the floor.** Inspiration is a gift; stealing the credit is theft.
  Every repo carries its sources.
